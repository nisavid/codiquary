# Contracts

This directory will contain the normative serialized contracts,
canonicalization rules, lifecycle semantics, error classes, extension rules,
and policy-profile meta-schema.

Normative shapes are closed by default. Extensions are explicit, namespaced,
and signature-bound. Unknown required security data fails as unsupported.
Readers support declared contract versions; writers emit one configured
version. Migration is explicit, deterministic, and auditable.

No contract source has been materialized yet.
