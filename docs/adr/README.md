# Architecture decision records

Normative or security-boundary changes require an ADR. Each record should state
the context, decision, authority effect, alternatives, compatibility and
migration consequences, conformance changes, threat-model impact, and status.

Accepted records:

- [ADR 0001: Use the hosted DCO app for contribution attestation](0001-use-hosted-dco-app.md)

The provenance handoff links the pre-repository decisions that constrain the
genesis work.
