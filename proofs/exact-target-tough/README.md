# Disposable exact-target Tough proof

This unpublished nested package is an experimental proof for the accepted
`exact-target-v1` investigation. It is not part of Codiquary's root package,
primary distribution, public API, production dependency graph, or release
authority.

The current source is deliberately incomplete. It contains only the dependency
checkpoint foundation: the proof manifest, deterministic public-source
preparation, dependency-declaration prefixes for the first two Tough patches,
and the empty library target Cargo needs for graph resolution. It contains no
verifier behavior, fixtures, or test result.

Follow the single procedure in
[`docs/agents/replay-exact-target-tough-proof.md`](../../docs/agents/replay-exact-target-tough-proof.md).
Do not build or test this package until both resolved Cargo graphs have been
reviewed and frozen.
