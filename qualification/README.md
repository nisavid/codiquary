# Qualification

A qualification record binds exact implementation and interface versions,
platform and relevant dependency or provider versions, profile and capability
scope, positive and hostile results, permission and secret-handling boundaries,
readback and recovery behavior, fixture and evidence digests, reviewer,
limitations, and invalidation triggers.

Records are immutable evidence about a completed evaluation. Suspension or
retirement is a new prospective status record and does not rewrite history. No
implementation or adapter is currently qualified.
