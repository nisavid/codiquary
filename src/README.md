# Core implementation

This directory is reserved for one primary core distribution. Its future
internal seams include release and status authority, producer preparation,
verification and bootstrap, publication coordination, protected-consumer
admission results, and the compact operator surface.

The [substrate decision](https://github.com/nisavid/codiquary/issues/2) selects
one root Rust 2024 package and library named `codiquary`, with the future
`cophax` operator command. The
[build-skeleton ticket](https://github.com/nisavid/codiquary/issues/8) owns the
initial build code. Module layout and the public API remain design work.
