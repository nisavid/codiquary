# Policy profiles

A public policy profile is complete, flattened, immutable, non-secret, and
identified by publisher-qualified name, version, and digest. It selects
compatible contracts and adapter capabilities and may narrow authority, never
expand it.

Runtime behavior does not depend on implicit inheritance, ambient merging, or
unrecorded overrides. Private deployment bindings and resolved secret values do
not belong here. No profile has been published yet.
